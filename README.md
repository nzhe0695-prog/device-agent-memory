# device-agent-memory

一个长期驻留在 Android 设备上的对话 agent 的**记忆分层实现**工程记录。

不是框架，也不是可运行的产品：是一台真实设备、连续运行两个月的实践记录——结构、阈值、踩过的坑，以及哪些结论只在特定前提成立。

## 读什么

- [`notes/device-agent-memory.md`](notes/device-agent-memory.md) — 正文。七层记忆结构、上下文预算与前缀稳定性、11 例故障（现象 / 根因 / 修复）、适用边界。
- [`sample/`](sample/README.md) — 记忆文件的**脱敏样本**：结构与字段保留，正文全部掩码。
- [`tools/sanitize-export.mjs`](tools/sanitize-export.mjs) — 脱敏导出脚本，带自检。

最短路径（只看结论）：

1. **§1.2** — 七层结构表（载体 / 更新频率 / 体积 / 注入策略），一屏看完。
2. **§2.4** — 缓存前缀的三种坏法。如果只改一件事来省钱，改这里。
3. **§3.9 / §3.10** — 两条"上层症状极具误导性"的故障：`EACCES` 被误诊成业务故障；自启失败表现为"什么都没发生"。
4. **§4** — 适用边界。六条不建议采用的场景，先看这个再决定要不要抄。

## 前提

- Android 16 / Termux，普通 app uid，**无 root**
- 单机单实例；纯文本 + JSON 存储，无向量库、无数据库
- 单轮上下文目标 ≤ 8K token
- 交互通道：系统通知（入向）+ 自建无障碍服务（读屏 / 点击 / 输入 / 截图）

## 数据说明

`sample/` 来自真实运行数据，经脚本处理：

| 原始 | 替换为 |
|---|---|
| 连续中文（≥2 字） | `<cjkN>` |
| 5–12 位整数、13 位时间戳 | `<numN>` / `<ts>` |
| IP / URL / 邮箱 / 手机号 / 密钥 / 本机路径 | 对应占位符 |

保留目录结构、Markdown/JSON 字段名、日期、字数桶。自检：导出后重新扫描，若仍出现连续中文、≥6 位整数或 IP 段即失败。

**注意**：即使掩码，字数分布与时间分布仍可推断活动强度，请勿将本仓库样本当作"完全匿名"的数据使用。
